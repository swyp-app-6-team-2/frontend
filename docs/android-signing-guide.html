Google · Firebase

구글 — SHA-1 지문 등록

Firebase Console → console.firebase.google.com (이 앱은 FCM을 써서 Firebase 경로가 가장 쉬움)

  1. 프로젝트 → ⚙️ 프로젝트 설정 → 내 앱 → Android 앱 (com.byeolddameokja.app) 선택
  2. SHA 인증서 지문 → 지문 추가
  3. 아래 SHA-1 붙여넣기 (SHA-256도 함께 넣으면 더 안전)
  4. Firebase에 넣으면 연결된 GCP OAuth 클라이언트에 자동 반영. (Firebase 미사용 시 GCP 콘솔 → 사용자 인증 정보 → Android용 OAuth 클라이언트에 직접 추가)

Naver

네이버 — 패키지명 등록

Naver Developers → developers.naver.com/apps

  1. 해당 앱 → API 설정 → 로그인 오픈 API 서비스 환경 → Android
  2. 패키지 이름 com.byeolddameokja.app + 다운로드 URL(테스트면 임의 Play URL 가능) 등록
  3. 네이버는 주로 패키지명으로 매칭. 콘솔이 SHA-1을 요구하면 위 EAS SHA-1 사용

등록 전 확인 / 주의
  • 같은 구글 프로젝트여야 함 — dev 백엔드가 검증하는 GOOGLE_CLIENT_ID와 동일 프로젝트에 Android 지문을 넣어야 통과. 다른 프로젝트에 넣으면 계속 실패.
  • 리빌드 불필요 — APK 서명은 고정. 콘솔에 등록·저장하면 기존 APK에서 바로 로그인 재시도(보통 수 분 내 반영).
  • 서명키가 다르면 값도 다름 — 공유 APK는 EAS 서명(위 값). 로컬 expo run:android까지 테스트하려면 debug SHA-1도 함께 등록.
